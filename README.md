# 🍕 Urban Crust - High-Performance React Food App

A modern, high-performance E-commerce frontend for a restaurant built with **Next.js 14** and **Tailwind CSS**. This project demonstrates advanced frontend capabilities, including real-time UI synchronization and responsive design.

---

---

## 🚀 Tech Stack

* **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **State Management:** React Hooks & Custom DOM Events for decoupled component communication.
* **Optimization:** Next/Image for lazy loading and layout stability.

---

## ✨ Key Features

* ✅ **Dynamic Cart Synchronization:** Real-time updates between the Cart Page and Navbar using a custom Event-driven architecture (No heavy libraries needed).
* ✅ **Interactive Price Logic:** Live price calculations based on selected sizes and toppings.
* ✅ **Responsive Layout:** Fully optimized for Mobile, Tablet, and Desktop views.
* ✅ **Clean Architecture:** Modular component structure for high maintainability.
* ✅ **Smooth UX:** Hover effects, active states, and optimized transitions.

## 🛠️ Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/KhalilArian/urban-crust.git
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open the app:**
    Visit [http://localhost:3000](http://localhost:3000).

---

## 📁 Project Structure

* `src/app`: App Router pages and layouts.
* `src/components`: Reusable UI elements (CartIcon, Price, Navbar).
* `src/data`: Mock data for product listings.
* `public`: Assets and static images.
